## 🛠️ Herramientas utilizadas
- **Tailwind CSS**
- **Angular 20**

---
⚠️ Nota importante

Si usas Bootstrap, es recomendable no combinarlo con Tailwind o PrimeNG.
En mi experiencia, suelen aparecer inconsistencias y conflictos de estilos, lo que complica la maquetación.
